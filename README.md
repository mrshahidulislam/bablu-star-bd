BABLU STAR BD Telegram Microjob Bot
Deploy:
Upload bot.py and requirements.txt to Inject Cloud.
Set environment variables BOT_TOKEN and ADMIN_ID (your numeric Telegram ID).
Install: pip install -r requirements.txt
Start command: python bot.py
SQLite file bablu_star_bd.sqlite3 is created automatically. Ensure Inject Cloud persistent storage is enabled. Deposits and withdrawals are manually reviewed by the admin; this code does not transfer money automatically. Use the official payment number/instructions you control. Test with test accounts before public launch. The category minimums are starter suggestions editable in CATS.
